## 3. Decisões que não são defeitos (intencionais)

- API em português e banco em inglês (`responsavelId` × `responsibleId`).
- `fotoEntradaId` obrigatório na API e opcional no banco (dados anteriores).
- `Animal.unitId` obrigatório no banco e opcional na API (resolvido pelo servidor).
- Atendimentos sem `DELETE`; `tipo` imutável após criado.
- Contato do responsável visível ao autor da própria alteração (`POST`/`PATCH`).
