# Decisões pendentes

Consolida o que depende da equipe da Ampara. **Nenhuma alternativa abaixo foi escolhida como aprovada**, e nada foi implementado com base em suposição: o sistema se comporta como descrito na coluna "Comportamento atual", que é o que existe no código e está coberto por teste. Referências: `regras-de-negocio.md` (RN, EQ), `requisitos-funcionais.md` (RF), `relatorio-incoerencias.md` (INC).

**Status:** _Aberta_ = aguarda decisão; _Aberta — com comportamento provisório_ = o código já faz algo e isso **não** é decisão aprovada.
